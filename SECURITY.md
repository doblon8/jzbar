# Security Policy

## Supported Versions

Security fixes are provided for the latest released version of this project.

Older versions may not receive security updates. Users are encouraged to upgrade to the latest release.

## Reporting a Vulnerability

If you believe you have found a security vulnerability, please report it privately by email to:

**doblon8@proton.me**

Please do not report security vulnerabilities through public GitHub issues.

When possible, include:

* A description of the vulnerability and its potential impact
* Steps to reproduce the issue
* A minimal proof of concept
* The affected project version
* Any relevant environment or platform details

Reports will be acknowledged as soon as reasonably possible. The issue will be investigated, and the reporter may be contacted for additional information.

If the vulnerability is confirmed, a fix will be developed and released as appropriate. Public disclosure will be coordinated after a fix is available or after the issue has otherwise been addressed.
